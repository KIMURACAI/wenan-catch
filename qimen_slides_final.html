隐干用法 & 占卜发用定律 四种隐干 · 年命/日干/时干/用神宫
四种隐干

天盘隐干 ← 天盘星原宫地盘干（遗传基因）

主现在·显露之事

人盘隐干 ← 八门原宫地盘干

主八门隐藏状态

暗干 ← 时干加值使门阳顺阴逆

三角交叉点显示隐藏信息

应期干 ← 时干加中宫

判断时间应期

占卜发用 · 四宫定律

年命宫：自身宫，信息大于日干一半

年命+坐宫+日干+时干+日支同宫=自身宫

日干宫：求测者目前状态

需与年命/日支/方位重合才准确

时干宫：求测人目前事情状态

时干+用神同宫 → 才代表求测事

用神宫：用神+年命同宫为准确

明宫·暗宫：年命宫=明 / 对宫=暗

六亲占卜秘诀 核心重要 · 不用找用神
男命六亲（年命壬为例）

妻子 → 他克不同性（壬→丁）

第三者 → 他克同性（壬→丙）

父亲 → 生他同性（壬→庚）

母亲 → 生他不同性（壬→辛）

儿子 → 他生同性（壬→戊）

女儿 → 他生不同性（壬→己）

官位 → 克他不同性 · 小人 → 克他同性

女命六亲（年命丙为例）

丈夫 → 克她不同性（丙→癸）

第三者 → 克她同性（丙→壬）

母亲 → 生她同性（丙→己）

父亲 → 生她不同性（丙→戊）

女儿 → 她生同性（丙→戊）

儿子 → 她生不同性（丙→己）

官位 → 她克不同性 · 小人 → 她克同性

关键：夫妻同宫感情不好 · 对宫相冲感情变动

三传用法秘诀（壬遁结合法）初传 · 中传 · 末传 —— 事物发展三部曲
三传结构

初传 → 中传 → 末传

地盘值符宫 → 天盘值符宫 → 值使门落宫

开始 → 过程 → 结束

落宫分析

三传同宫 伏吟，拖沓，抓源头

初+中同宫 开始与中间密不可分

初+末同宫 首尾呼应，重视开始

中+末同宫 关键在中间阶段

策划应用

天盘克地盘 = 利客 → 主动去做

地盘克天盘 = 利主 → 谨慎行事

应期判断

初生中、中生末 → 慢，拖沓

三传同宫（伏吟）→ 慢

初末同宫（反吟）→ 快

初克中、中克末 → 发展快

末传落宫数 = 事情结束天数

胎产断男女秘诀 主客法 · 直接占测与间接占测
关键区分

直接占测 孕妇自己问 → 直接看坤宫

间接占测 亲属代问 → 用六亲找对应宫

判断步骤

① 看坤宫天盘星阴阳

阳星：蓬、任、冲、辅

阴星：英、芮、柱、心

② 星与天干阴阳相同 → 直接定

阳星阳干=男 / 阴星阴干=女

③ 星与天干不同 → 改看八门阴阳

胎的判断：年命/日干处于十天干"胎"状态 = 已怀孕

示例

直接占例：1978年女，阳4局

坤宫天蓬星（阳星）+ 丁（阴干）

星与干不同 → 改看八门

休门（阳门）→ 男孩 ✓

间接占例：1983男代问妻生产

用六亲推：女→丙，兄弟→丁，其妻→庚

8宫天辅星（阳）+ 庚（阳）+ 伤门（阳）

→ 男孩 ✓
